アプリを使わずに解いた問題をクリックして「やった」に登録します（もう一度クリックで解除）。
登録した問題は新規セッションの出題対象から外れ、進行中のセッションでも自動的に飛ばされます。

出題設定

パート名・問題数は自由に変更可（行の追加・削除もOK）。別の冊子に移るときは問題数を書き換えて「新規セッション開始」。

パート問題数

全体シャッフル：同じパートが3問以上続かないように混ぜる／パート順シャッフル：パート1から順に、パート内だけ混ぜる

GitHub 同期

記録は GitHub リポジトリの data/records.json に保存されます。書き込みには自分の Personal Access Token が必要です（このブラウザにだけ保存され、リポジトリには含まれません）。
